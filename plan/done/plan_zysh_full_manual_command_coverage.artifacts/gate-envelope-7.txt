3. Key Empirical Discoveries for Envelope 7
------------------------------------------------------------------------------
1. Prompt Regex Submode with Spaces:
   - When entering submodes with multi-word identifiers (e.g. 'bwm append'
     producing prompt 'Router(config-bwm append 2)#'), the ssh client's
     prompt regex must allow spaces inside parenthesis delimiters
     (pattern: R"((?:[\r\n]|^)[\w.-]+(?:\([^()\r\n]+\))?[>#]\s*$)").
   - This eliminates 5000ms drain timeouts during submode mutations.

2. Application Patrol Multi-Block Aggregation:
   - 'show app statistics summary' returns separate blocks for each
     monitored application (HTTP, Netflix, etc.).
   - Parsers must aggregate/accumulate counters across all application
     sections rather than overwriting with the final entry.

3. Profile Submode Navigation:
   - 'ssl-inspection profile <name>' enters submode
     'Router(config-ssl-inspection-profile-<name>)#'.
   - 'anti-virus <name>' enters submode 'Router(config-av-profile-<name>)#'.
   - 'app <name>' enters submode 'Router(config-app-patrol-profile-<name>)#'.
   - Deletion requires exiting to 'Router(config)#' and executing
     'no <subsystem> [profile] <name>'.

4. Desktop Gateway Unsupported UTM Subsystems:

     return '% Parse error' or require cloud platform licenses not active on
